## General Production Notes

### Recording Tips
- Use Roblox Studio's built-in video capture or OBS
- Set graphics quality to max for best visuals
- Record at 60fps when possible
- Use in-game camera for smooth cinematic shots
- Add slow-motion in post for dramatic moments

### Audio
- Record game audio separately for mixing flexibility
- Add royalty-free background music
- Include satisfying sound effect layers

### Post-Production
- Keep TikTok clips fast-paced (cut every 1-3 seconds)
- Add text overlays for key moments
- Use trending audio where appropriate
- Color grade for consistency across all game videos

### Thumbnail Specs
- YouTube: 1280x720, bright colors, action shot, text overlay
- TikTok: 1080x1920, face/character if possible, bold text
