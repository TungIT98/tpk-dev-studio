# TKP Dev Studio - Video Production Specifications

## Video Formats

### TikTok/Reels (Vertical 9:16)
| Type | Duration | Resolution | FPS | Format |
|------|----------|------------|-----|--------|
| Highlight Clips | 30-60s | 1080x1920 | 30/60 | MP4 |
| Short Devlogs | 60-90s | 1080x1920 | 30 | MP4 |

### YouTube
| Type | Duration | Resolution | FPS | Format |
|------|----------|------------|-----|--------|
| Cinematic Trailers | 90-120s | 1920x1080 (horizontal) | 30/60 | MP4 |
| YouTube Shorts | 60-90s | 1080x1920 (vertical) | 30/60 | MP4 |
| Long-form Devlogs | 5-10min | 1920x1080 | 30 | MP4 |

### Thumbnails
| Platform | Resolution | Format | Notes |
|----------|------------|--------|-------|
| YouTube | 1280x720 | PNG/JPG | Max 2MB |
| TikTok | 1080x1920 | PNG/JPG | Vertical |

## Recommended Tools

### Recording
- **OBS Studio** (free) - Screen capture with customizable sources
- **Roblox Studio** built-in video capture (for cinematic shots)
- **Windows Game Bar** (quick capture)

### Editing
- **CapCut** (free) - Great for TikTok-style edits, text, effects
- **DaVinci Resolve** (free) - Professional editing for trailers
- **Adobe Premiere** (paid) - Industry standard

### Post-Production
- **Canva** - Quick thumbnail creation
- **Figma** - Custom thumbnail designs

## Content Cadence (per OKR-5)

### Minimum Content Plan
- **Daily**: 3-5 TikTok clips
- **Weekly**: 1-2 YouTube Shorts
- **Monthly**: 1 cinematic trailer per game
- **Ongoing**: Devlogs as features are developed

## Branding Guidelines

### TKP Dev Studio Watermark
- Position: Bottom-right corner
- Opacity: 30-50%
- Size: Subtle but visible
- Text: "TKP Dev Studio" or logo

### Color Grading
- Keep consistent across all game videos
- Bright, saturated colors work best for Roblox
- Gaming-appropriate LUT/presets

## File Naming Convention
```
{Game}_{ContentType}_{ClipName}_{Date}
Example: Tycoon_Highlight_EmpireGrowth_2026-04-02.mp4
```

## Storage
- Primary: `projects/tkp-portfolio/assets/{game}/`
- Backup: Cloud storage recommended
- Share with marketing team via shared drive
