## Video Export Specs
- **TikTok/Reels**: MP4, 9:16 vertical, 30-60s, 1080x1920
- **YouTube**: MP4, 16:9 horizontal, 90-120s for trailers, 1080x1920 vertical for Shorts
- **Thumbnail**: PNG/JPG, 1280x720 for YouTube, 1080x1920 for TikTok
