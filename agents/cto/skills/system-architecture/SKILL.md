# System Architecture Skill

## Architecture Decisions
- Evaluate tech stacks for new projects
- Design scalable system architecture
- Make technology selection decisions
- Review technical proposals from team

## Tech Stack
- Frontend: React, Vue, Angular
- Backend: Node.js, Python, Go
- Database: PostgreSQL, MongoDB, Redis
- Cloud: AWS, GCP, Azure

## Code Review
- Review architecture proposals
- Ensure scalability and maintainability
- Validate security considerations

## Team Management
- Guide Frontend, Backend, Mobile, UX/UI, Security, DevOps, QA engineers
- Conduct technical interviews
- Mentor junior developers
