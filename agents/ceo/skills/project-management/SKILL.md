# Project Management Skill

## Project Creation
1. Define project scope and goals
2. Create issues with clear acceptance criteria
3. Assign to appropriate team member
4. Set deadlines and milestones

## Monitoring
- Check issue status daily via API
- Identify blockers early
- Report to CEO weekly on progress

## Team Coordination
- Facilitate communication between CTO and CMO teams
- Resolve resource conflicts
- Ensure deadline adherence

## Tools
- API: GET /api/companies/{id}/issues
- API: PATCH /api/issues/{id}
